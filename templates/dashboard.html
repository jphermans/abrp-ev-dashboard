❓ Help — Hoe het dashboard werkt

📊 KPI Kaarten

🛣️

Totaal gereden

Alle gereden kilometers in de geselecteerde periode. Het getal eronder toont het aantal ritten.

⚡

Totaal bijgeladen

Totaal aantal kWh bijgeladen via alle laadsessies. Het getal eronder toont het aantal laadsessies.

📊

Verbruik

Gemiddeld energieverbruik in kWh per 100 km. Berekend als: totale kWh bijgeladen ÷ totale km × 100. Lager = efficiënter rijden.

📅

Actieve dagen

Aantal unieke dagen waarop gereden is. Subtekst toont gemiddelde km per actieve dag.

🔌

Top provider

Welke laadprovider je het meest gebruikt (bijv. DATS 24, Fastned, Allego). Subtekst toont hoe vaak je daar geladen hebt.

🏆

Langste rit

De langste enkele rit in kilometers binnen de geselecteerde periode.

⚡ Laadstatistieken & Providers

🔌

Laadsessies per provider (donut grafiek)

Toont het aantal laadbeurten per provider. Elke kleur represents een andere provider:

DATS 24 🟠 Fastned 🔵 Allego 🔷 Shell Recharge 🔴 Andere 🟣

⚡

Energie per provider (balkgrafiek)

Toont hoeveel kWh je per provider hebt bijgeladen. Nuttig om te zien waar je de meeste energie haalt.

📍

Laadlocaties tabel

Overzicht van elke laadlocatie met het aantal sessies, totale kWh, en wanneer je er voor het laatst geladen hebt.

📊 Rijstatistieken

📊

Afstand per periode

Balkgrafiek met totale km per dag, week, maand of jaar — afhankelijk van het actieve filter.

⚡

Energie bijgeladen

Balkgrafiek met totale kWh bijgeladen per periode.

🔋

Batterij SoC verloop

Lijndiagram van de gemiddelde batterijlading (State of Charge) bij start van elke periode. Een dalende lijn betekent dat je gemiddeld met minder batterij begint te rijden.

🏁

Kilometerteller (cumulatief)

Lijndiagram van de kilometerstand van de wagen over tijd. Toont hoe snel de wagen slijt.

📅

Ritten per weekdag

Balkgrafiek met aantal ritten per dag van de week (Ma-Zo). Helpt inzichtelijk maken op welke dagen je het meest rijdt.

🛣️

Afstand verdeling

Donut grafiek met verdeling van ritten in afstandscategorieën: 0-10 km (kort), 10-50 km (woon-werk), 50-100 km (regionaal), 100-200 km (lang), 200+ km (zeer lang).

🔀 Tijdfilters

Met de filterknoppen bovenaan kies je hoe de data wordt gegroepeerd:

  • Dag — Elke individuele dag als aparte kolom/rij
  • Week — Gegroepeerd per ISO-weeknummer
  • Maand — Gegroepeerd per maand (standaard)
  • Jaar — Jaartotalen
  • Alles — Alle data samengevoegd als één periode

Alle grafieken updaten onmiddellijk bij het wijzigen van filter.

📂 Data toevoegen

📤

Excel Upload

Klik op 📂 Upload en selecteer één of meer ABRP Excel exports. De server parset de bestanden, converteert mijlen naar km, detecteert laadproviders, en merget alles samen. Bestanden worden lokaal opgeslagen.

🚗

Volkswagen WeConnect

In ⚙️ Instellingen kun je je VW account koppelen (gratis). Klik op 🔄 Sync om ritten en laaddata direct van Volkswagen servers op te halen.

🔑

ABRP API Token

Voor premium ABRP API keys. Sla je token op in ⚙️ Instellingen om activiteiten rechtstreeks van ABRP op te halen.

⚙️ Instellingen

🌙

Donker / Licht thema

Schakel tussen donker en licht uiterlijk. Voorkeur wordt in je browser opgeslagen.

🌈

Kleurenpalet

Kies uit 6 kleurenpaletten: Default, Warm, Ocean, Forest, Sunset, Mono. Alle grafieken kleuren onmiddellijk mee.

📄 Export

Klik op 📄 PDF om het volledige dashboard (alle kaarten, grafieken en tabellen) op te slaan als een PDF rapport. De PDF bevat meerdere pagina's als het dashboard niet op één pagina past.

📱 Mobiel

Het dashboard werkt op telefoons en tablets. KPI-kaarten tonen in 2 kolommen, grafieken stapelen verticaal, en tabellen scrollen horizontaal met touch. Alle data blijft beschikbaar — niets wordt verborgen.

🔒 Privacy

Alle data blijft lokaal op je Raspberry Pi. De server stuurt geen data naar externe servers, tenzij je expliciet WeConnect of ABRP API gebruikt. Credentials worden opgeslagen in data/vw_config.json (lokaal, niet in de browser).

Dit is je eerste login met het standaardwachtwoord. Kies een nieuw wachtwoord om door te gaan.
